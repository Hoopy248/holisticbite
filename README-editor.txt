HOLISTICBITE — редактор сайта

1. Распакуйте архив. Загрузите его содержимое (файлы и папки api, lib, work) в корень ветки calendar-admin на GitHub с заменой существующих файлов. Сам ZIP загружать не нужно.
2. Дождитесь Ready у нового деплоя Vercel. Откройте /admin.html на адресе этого деплоя и обновите страницу Ctrl+F5.
3. В кабинете появится «Редактор сайта»: тексты, отзывы и форматы консультаций. Выберите RU, EN или ET. Пустой перевод использует русский текст.
4. «Сохранить черновик» сохраняет правки без изменения сайта. «Предпросмотр» открывает сохранённый черновик; запись в нём отключена. «Опубликовать» применяет правки для клиентов.
5. Отзывы и форматы можно добавлять, скрывать и менять местами. У форматов редактируются описание, состав и цены в рублях/евро. Для публикации нужен хотя бы один видимый формат.

Новые переменные Vercel не нужны: используются уже подключённый Redis и текущий вход администратора. Контент хранится отдельно от расписания. Существующие записи и даты сохраняются.

Важно: ветка calendar-admin создаёт Preview. Чтобы изменения появились на основном holisticbite.vercel.app, после проверки объедините calendar-admin с main через Pull Request. Переменные Redis и входа должны быть доступны также для Production.

Редактор охватывает тексты главной страницы и её окон. Отдельные страницы анкеты и карты тела в эту версию редактора не входят. Автоматического перевода нет.

Архив включает предыдущее обновление календаря с закрытыми по умолчанию датами. Демонстрационные правки и секреты в архив не включены.
